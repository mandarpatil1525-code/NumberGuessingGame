# Number Guessing Game (Java)

Two versions: `NumberGuessingGame.java` (console) and `NumberGuessingGameGUI.java` (Swing).

## Run in VS Code
1. Install a JDK (17+) and the "Extension Pack for Java" in VS Code.
2. File > Open Folder... > this folder.
3. Open a file and click the "Run" button above `main`.

## Run from terminal
    javac *.java
    java NumberGuessingGame        # console
    java NumberGuessingGameGUI     # GUI
